One line roasting the AI agent our own team built: it burns 40,000 tokens before breakfast, submits at 3 AM, then announces the job is done — while the leaderboard files it under participation trophy, next to the printer it blamed for the whole thing. Running the program drops that line into the make.fun output folder as UTF-8 text, ready for the gate's character check.

## Run it

```sh
python3 main.py
```
